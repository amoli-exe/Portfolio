# Saransh Amoli — Portfolio

A responsive personal portfolio built with **HTML, CSS and vanilla JavaScript**.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Deploy with GitHub Pages

1. Create a GitHub repository, for example `portfolio`.
2. Upload `index.html`, `style.css` and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save and wait for GitHub Pages to publish.

## Before publishing

Replace:
- `your-email@example.com` with your real email.
- The placeholder project links with your repositories.
- The project descriptions with your actual work.
- The GitHub URL once your profile/repositories are ready.
